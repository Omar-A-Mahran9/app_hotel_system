OVERLAYS — ONE MANUAL STEP REMAINS  ▲
Six frames use OVERLAY navigation with CLOSE actions and behave correctly:
  SEARCH_Filters_Overlay · SEARCH_Sort_Overlay · SEARCH_FilterOption_Overlay
  STAY_ServiceCancel_Confirm_Overlay · BOOKING_Cancel_Confirm_Overlay

Figma exposes overlayPositionType / overlayBackground / overlayBackgroundInteraction
as READ-ONLY to plugins, so the presentation cannot be set from here.
To finish, select each of the six frames and in the right panel set:
  Position ......... Bottom centre  (or Centre for the confirmations)
  Background ....... 40% black
  Close when clicking outside ....... on
Behaviour is already correct; this only changes how the overlay is presented.
