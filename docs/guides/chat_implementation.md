# Hotel Guest App --- Chat / Support Decision

## Status

Chat is NOT an approved MVP requirement in the current Hotel Management
baseline.

The source documentation from another project included a chat
implementation, but it must not be copied into the Hotel Guest App as a
current feature.

## Current Alternative

The approved MVP includes:

-   report a problem
-   service requests
-   notifications
-   backend-audited operational workflows

## Future Enhancement

A guest support chat may be added later only after:

1.  business approval
2.  API contract
3.  notification strategy
4.  moderation/security requirements
5.  backend architecture
6.  mobile UX approval

Until then, keep chat documentation as future/reference material only.
