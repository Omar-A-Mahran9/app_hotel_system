# Hotel Guest App --- Device Search Indexing

## Status

Device/system search indexing is a future enhancement, not an MVP
requirement.

The original source document described generic item indexing and must
not be copied as-is.

## Possible Future Use

If approved later, useful searchable Hotel entities may include:

-   a hotel
-   a booking
-   a room/stay shortcut
-   an approved service shortcut

## Requirements Before Implementation

-   approved UX
-   deep-link contract
-   privacy review
-   Android/iOS platform design
-   indexing/deindexing lifecycle
-   stale-data handling

Do not implement system search indexing during the initial Guest App
foundation unless explicitly approved.
